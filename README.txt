دفتر حسابات المواقع - PWA
==========================
1) فك الضغط عن الملف من تطبيق «الملفات» في Android (اضغط مطولًا على ZIP ← استخراج).
2) استضافة مجانية (إلزامية للتثبيت، لأن Chrome يشترط رابط https):
   - من Chrome على الهاتف افتح github.com وأنشئ حسابًا مجانيًا.
   - New repository ← الاسم: sitebook ← Public ← Create.
   - فعّل «موقع سطح المكتب» من قائمة Chrome (⋮) لتظهر الأزرار كاملة.
   - Add file ← Upload files ← اختر كل الملفات والمجلد icons (ارفع icons بملفاته الثلاثة)، ثم Commit.
   - Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save.
   - بعد دقيقتين يظهر الرابط: https://اسمك.github.io/sitebook/
3) افتح الرابط في Chrome ← ⋮ ← «تثبيت التطبيق» (Install app) أو «إضافة إلى الشاشة الرئيسية».
4) افتحه مرة واحدة وأنت متصل بالإنترنت ليحمّل ملفات العمل دون إنترنت، ثم يعمل بعدها بدون إنترنت.
5) النسخ الاحتياطي: من البرنامج ← النسخ الاحتياطي ← تصدير. احتفظ بالملف خارج الهاتف (واتساب/Drive).
6) تغيير الهاتف: ثبّت التطبيق على الهاتف الجديد ← النسخ الاحتياطي ← استعادة ← اختر ملف JSON.
ملاحظة: البيانات تُحفظ داخل متصفح هاتفك فقط. مسح بيانات Chrome أو إزالة التطبيق قد يمسحها، فاحتفظ بنسخ احتياطية.
